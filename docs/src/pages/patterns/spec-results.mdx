# SpecResults

## Usage

A run's status at a glance: how many specs failed, errored, passed, or skipped, and how many are still running or queued. Each count links to the Specs tab filtered to that status, and a bar along the bottom shows the same breakdown as proportion. Sits at the top of a run's detail tabs in Cypress Cloud.

<div class="border border-gray-100 rounded-lg my-4 p-4 bg-gray-25">
  <SpecResults />
</div>

```tsx
import { SpecResults } from '@cypress-design/react-spec-results'

export default () => (
  <SpecResults
    results={{ failed: 1, passed: 18, skipped: 1, running: 2, queued: 3 }}
    onCancel={() => {}}
  />
)
```

Package: `@cypress-design/react-spec-results` — React only for now, Vue is a planned fast-follow. See [`instructions.md`](https://design.cypress.io/agents/components/SpecResults/instructions.md) for the full props reference, every state (indeterminate, scheduled-to-complete, complete), and the status-mapping contract callers are expected to follow.
